# 🛡️ AI Scam & Phishing Detector

Aplikasi berbasis **AI & Analisis Heuristik** untuk mendeteksi pesan penipuan (Scam/Phishing) dan tautan berbahaya.

## Fitur
- 📧 **Analisis Pesan** — Deteksi teks email/SMS scam menggunakan NLP (TF-IDF + Random Forest)
- 🔗 **Analisis URL** — Deteksi phishing link berdasarkan analisis heuristik
